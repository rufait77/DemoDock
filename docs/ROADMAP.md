# Roadmap

DemoDock 0.1.0 focuses on a complete path from a frontend to a static, resettable demo. Future items are proposals, not delivery commitments.

- Broader browser coverage: Firefox, WebKit, and physical-device checks.
- Additional examples for dashboards, support inboxes, and ecommerce flows.
- Stable package publication to npm and a standalone create command.
- Integration recipes for TanStack Query and client-side routers.
- Accessible tour positioning and richer keyboard navigation.
- Framework adapters outside React, based on demonstrated demand.
- GraphQL and SSR integration research; these need explicit scope and tests.

Share the frontend stack, API shape, and a small example in an issue. Real integration friction is the most useful input for prioritization.
